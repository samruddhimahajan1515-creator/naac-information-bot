# NAAC Information Bot

An offline prototype for common NAAC accreditation preparation questions. It includes a browser-based chat demo and a Python desktop version.

## Browser demo

Open `index.html` in a modern browser. It needs no installation, server, or API key. Suggested questions cover NAAC, IQAC, SSR, process, evidence, data checks, grades, and deadlines.

## Python desktop app

Run with Python 3:

```bash
python naac_bot.py
```

The Python app uses Tkinter, which is included with most standard Windows Python installations.

## Limitations

These are demonstrations with a local question-and-answer set, not a connected LLM or live NAAC document collection. They are not official NAAC services and cannot answer every possible question. Verify cycle-specific requirements through current official NAAC publications.
